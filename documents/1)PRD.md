# PRD: AI 기반 미디어 모니터링 및 인사이트 대시보드

## 1. 제품 개요
뉴스 조직을 위한 내부용 AI 기반 미디어 모니터링 및 인사이트 대시보드.
다양한 데이터(랭킹 뉴스, 기사, 구독자 변화, 댓글 반응)를 통합하여
데이터 기반 편집 의사결정을 지원한다.

## 2. 목표 및 KPI
- 모니터링 시간 50% 이상 감소
- 미보도 이슈 탐지 증가
- 의사결정 속도 향상
- 일간 AI 요약 제공

## 3. 핵심 기능
### 기능 목록
| 기능 | 설명 |
|------|------|
| 랭킹 뉴스 비교 | 매체별 뉴스 랭킹 비교 |
| 이슈 클러스터링 | 키워드 기반 이슈 그룹화 |
| 트렌드 시각화 | 버블/맵 형태 트렌드 제공 |
| 미보도 탐지 | 경쟁사 대비 누락 이슈 탐지 |
| 구독자 분석 | 7일 변화 추적 |
| 댓글 분석 | 인기 및 반응 분석 |
| AI 요약 | 일간 주요 이슈 요약 |

## 4. 추가 기능 (Optional)
- 실시간 알림
- 개인화 대시보드
- 주제 필터링
- 장기 트렌드 분석

## 5. 사용자 페르소나
- 기자 및 에디터
- 디지털 콘텐츠 관리자
- 전략 분석가

## 6. 기술 스택
- Frontend: Streamlit → React
- Backend: Python
- DB: PostgreSQL
- AI: NLP 기반 클러스터링 및 요약

## 7. 보안 및 컴플라이언스
- 초기 내부 전용
- 향후 RBAC 적용
- 데이터 보안 저장

## 8. 참고 서비스
- Google News
- Naver News
- SimilarWeb
