# IA 문서: AI 기반 미디어 모니터링 대시보드

## 1. 개요
본 문서는 뉴스 조직을 위한 내부 AI 미디어 모니터링 시스템의 정보구조(IA)를 정의한다.

---

## 2. 사이트맵 (Site Map)

| Level 1 | Level 2 | Level 3 |
|--------|--------|--------|
| 대시보드 | 트렌드 개요 | 실시간 이슈 |
| 이슈 분석 | 클러스터 | 상세 이슈 |
| 경쟁사 비교 | 매체 비교 | 기사 비교 |
| 미보도 탐지 | 누락 이슈 | 추천 주제 |
| 구독자 분석 | 트렌드 | 상세 분석 |
| 독자 반응 | 댓글 분석 | 인기 기사 |
| AI 리포트 | 일간 요약 | 주간 리포트 |

---

## 3. 사용자 흐름 (User Flow)

1. 대시보드 접속
2. 주요 트렌드 확인
3. 특정 이슈 클릭
4. 경쟁사 비교 분석
5. 미보도 여부 확인
6. 기사 작성 방향 결정

---

## 4. 네비게이션 구조

### Desktop
- Topbar: 날짜, 검색, 알림
- Sidebar:
  - 대시보드
  - 이슈 분석
  - 경쟁사 비교
  - 미보도 탐지
  - 구독자 분석
  - 독자 반응
  - AI 리포트

### Mobile (Future)
- Bottom Navigation:
  - 홈
  - 이슈
  - 비교
  - 리포트

## 7. 인터랙션 패턴

- 클릭 → 상세 진입
- Hover → 요약 표시
- 필터 → 카테고리 변경
- Drill-down → 심층 분석
