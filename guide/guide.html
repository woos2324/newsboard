시작하기 — Newsboard는 무엇인가요?

Newsboard는 자사(세계일보)와 경쟁 매체의 뉴스를 실시간으로 수집·분석해, 편집국이 지금 무슨 일이 벌어지는지 한눈에 파악하도록 돕는 AI 미디어 모니터링 대시보드입니다. 이슈 클러스터링, 미보도 탐지, 실시간 검색 트렌드, 트래픽(조회수)·구독자 지표, AI 일간 리포트까지 모든 데이터는 자동으로 수집·갱신됩니다.

로그인

@segye.com 이메일 계정으로 로그인합니다. 계정은 회원가입(이메일 인증) 후 사용하며, 역할에 따라 보이는 메뉴가 다릅니다. 일정 시간(4시간) 이상 활동이 없거나 브라우저를 닫으면 자동 로그아웃됩니다.

회원가입 — 이메일 인증(6자리)

로그인 화면의 가입하기에서 진행합니다. 회사 이메일로 받은 6자리 인증번호로 본인 확인 후 계정을 만듭니다.

  1. 1이메일 입력 — @segye.com 주소만 가입할 수 있습니다
  2. 26자리 인증번호 입력 — 입력한 메일로 인증번호가 발송됩니다(10분 이내 유효). 메일이 안 오면 스팸함을 확인하세요
  3. 3이름 · 역할 · 비밀번호 설정 — 비밀번호는 8자 이상(대소문자·숫자·특수문자 포함)
✅기자(reporter) 계정은 인증 즉시 사용할 수 있습니다. 사업부(business) 계정은 최고관리자 승인 후 사용할 수 있어, 가입 직후에는 ‘승인 대기’ 화면이 표시됩니다. 사업부 가입 신청이 들어오면 최고관리자에게 알림이 전달되고, 최고관리자가 회원 관리에서 승인하면 바로 로그인됩니다.

비밀번호 찾기

로그인 화면의 비밀번호 찾기에서 진행합니다. 3단계입니다.

  1. 1이메일 입력 → 가입된 계정이면 6자리 인증번호 메일 발송(미가입 이메일은 안내 표시)
  2. 2인증번호 입력으로 본인 확인
  3. 3새 비밀번호 설정 → 변경되면 모든 기기에서 로그아웃되고 새 비밀번호로 다시 로그인합니다

대시보드

로그인 후 처음 만나는 화면. 오늘의 핵심 지표와 주요 이슈를 한 화면에 종합합니다. 5분마다 갱신됩니다.

images/10_dashboard.png (캡처 예정)
1 2 3 4
  1. 1지표 카드 4개 — 자사 오늘 기사 수 · 조회수(PV) · 총 구독자 · 댓글 반응. 카드를 클릭하면 관련 페이지로 이동(권한 있는 메뉴만)
  2. 2AI 일간 브리핑 — 오늘 이슈를 AI가 요약 (매일 자동 생성)
  3. 3주요 이슈 카드 · 실시간 트렌드 키워드 · 인기 기사 랭킹 · 미보도 알림
  4. 4구독자 추이 차트 · 인기 댓글 기사
💡조회수 카드는 오늘 실시간 누적 PV가 있으면 “오늘 실시간”으로, 없으면 전일 확정값으로 표시됩니다. 각 카드의 ▲/▼ 는 비교 기간 대비 증감입니다.

이슈 모니터링 — 이슈 클러스터 + 미보도 탐지

여러 매체 기사를 같은 사건끼리 묶은 이슈 클러스터를 보여주고, 경쟁사는 보도했지만 자사가 놓친 이슈(미보도)를 함께 표시합니다.

images/20_issue_list.png (캡처 예정)
1 2 3 4
  1. 1날짜 이동 — 화살표 또는 달력으로 다른 날짜 이슈 보기
  2. 2필터 탭 — 전체 / 미보도만 / 검토중
  3. 3커버리지 배지 — 미보도 확인필요 유사보도있음 보도함 · 우선순위(높음/보통/낮음) · 신뢰도
  4. 4검토 버튼(미보도 처리 상태 변경) · 상세보기로 이슈 내 기사 전체 보기

미보도 카드에는 탐지 시각, 먼저 보도한 경쟁사(클릭 시 원문), 그리고 자사 유사 기사(있으면)가 함께 표시되어, 정말 놓친 건지 빠르게 판단할 수 있습니다.

💡왼쪽 메뉴의 “미보도 탐지”로 들어오면 자동으로 이슈 모니터링의 ‘미보도만’ 필터로 연결됩니다. 같은 화면입니다.

이슈 상세보기

카드의 상세보기를 누르면 이슈 하나를 깊이 들여다보는 화면이 열립니다. 한 사건에 어느 매체가 어떻게 보도했는지 전체 맥락을 파악할 수 있습니다.

이슈 클러스터 정보

제목 · 요약 · 키워드 · 신뢰도 · 관련 기사 수 · 보도 매체 수

AI 이슈 요약

이 이슈의 핵심을 AI가 정리(제목·요약·포인트). 없으면 ‘이 이슈 요약 생성’ 버튼으로 즉석 생성

관련 기사 목록

이슈에 묶인 전 매체 기사를 유사도 순으로. ★ 대표 기사 표시 · 매체·섹션·발행시각·유사도 % · 클릭 시 원문

초안 상세 화면 · 기자 문체 학습

초안이 완성되면 상세 화면으로 이동합니다. 좌측에 기사 본문, 우측에 근거 팩트 패널(출처 매체별 요약·수치·인용·배경, 참고 이미지)이 나란히 배치돼, 작성된 문장과 그 근거를 바로 대조할 수 있습니다. 상단에는 ‘AI 생성 초안 · 사실관계 검증 필수 · 데스크 검수 후 발행’ 경고 배지가 항상 표시됩니다.

🧠

기자별 문체로 작성

각 기자가 과거에 쓴 기사를 주제·유형 섞어 18건(각 1,500자) AI가 미리 분석해 문체 프로파일(리드 방식·문장 길이·톤·구조·수치 처리·인용 배치·마무리 패턴·자주 쓰는 표현)을 학습해 둡니다. 본인 계정으로 작성하면 그 기자 문체를 반영하고, 작성 시 본인 기사 6건을 예시로 함께 보여줘 문체를 재현합니다.

📚

학습 현황

현재 세계일보 기자 215명의 문체가 학습돼 있습니다. 학습 데이터가 없는 계정(예: 관리자 또는 신규 기자)은 문체 없이 팩트 기반으로만 초안을 작성합니다.

⚠️AI 생성 초안이므로 그대로 발행하지 마세요. 수치·인용 등 사실관계를 반드시 확인하고(확인이 필요한 곳은 [확인필요] 표시) 데스크 검수 후 발행해야 합니다.

트래픽 분석 — 조회수 · 유입 경로

네이버 파트너센터에서 수집한 자사 기사 조회수(PV)와 유입 경로를 분석합니다. (트래픽·구독자 메뉴는 사업부·관리자 전용)

  2. 2KPI 4개 — 총 조회수 · 1위 기사 PV · 피크(급증) 시간대 · 검색 유입 비중

자주 묻는 질문 · 팁

메뉴가 안 보여요.
역할에 따라 메뉴가 다릅니다. 예를 들어 기자는 트래픽·구독자 메뉴가, 사업부는 이슈·트렌드·비교 메뉴가 보이지 않습니다. 권한이 필요하면 최고관리자에게 역할 변경을 요청하세요.
로그인이 자꾸 풀려요.
보안을 위해 4시간 이상 활동이 없거나 브라우저를 닫으면 자동 로그아웃됩니다. 다시 로그인하면 됩니다.
비밀번호를 틀려서 계정이 잠겼어요.
5회 연속 실패 시 잠깁니다. 최고관리자가 회원 관리에서 ‘잠금 해제’를 해주면 다시 로그인할 수 있습니다.
‘미보도’는 정확한가요?
AI가 경쟁사 보도와 자사 기사를 비교해 추정한 것입니다. 카드의 자사 유사 기사와 먼저 보도한 경쟁사를 함께 확인하고, 필요하면 ‘검토’로 상태를 표시하세요.
트렌드에서 만든 초안을 바로 발행해도 되나요?
아니요. AI가 생성한 초안이므로 사실관계(수치·인용)를 반드시 확인하고 데스크 검수 후 발행해야 합니다. 확인이 필요한 부분은 [확인필요]로 표시됩니다.
데이터는 얼마나 자주 갱신되나요?
메뉴마다 다릅니다. 수집은 아래 주기로 자동 진행되고, 수집이 끝나면 화면도 곧 갱신됩니다(대부분 화면은 5분 캐시로 빠르게 열립니다).
