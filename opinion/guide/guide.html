시작하기 — 이 앱은 무엇인가요?

사설 분석(opinion)은 매일 수집되는 국내·해외 주요 언론사 사설을 주제별로 모아 보고, AI로 논조를 비교·분석하는 논설실 전용 도구입니다. 사설 수집·번역·성향 분석은 자동으로 매일 갱신됩니다.

오늘의 사설

당일 수집된 국내 주요 언론사 사설을 같은 주제끼리 묶어 보여줍니다. 매체 간 주장을 한눈에 비교할 수 있습니다.

images/10_today_list.png (캡처 예정)
1 2 3 4
  1. 1날짜 이동 — 화살표 또는 달력으로 다른 날짜 사설 보기 (‘오늘’ 버튼으로 복귀)
  2. 2필터 — 전체 / 종합일간지 / 경제지 / 매체별(신문사 단위로 묶기)

  4. 4사설 행을 클릭하면 상세 모달이 열립니다 · 더보기 +N건으로 그룹 내 전체 보기

주제 수동 보정 — AI가 잘못 묶었을 때

AI가 묶은 주제가 어색하면, 편집자가 직접 올바른 주제로 옮길 수 있습니다.

images/12_today_topic.png (캡처 예정)
1 2
  1. 1사설 행에 마우스를 올리면 나타나는 주제 변경 클릭
  2. 2펼쳐진 패널에서 기존 주제 후보를 클릭해 옮기거나 + 새 주제로 직접 입력
💡수동 보정한 주제는 이후 AI 재분류에도 덮어쓰이지 않고 보존됩니다. 이미 보정한 사설은 같은 패널의 자동으로 되돌리기로 AI 분류로 되돌릴 수 있고, ‘보정’ 배지가 표시됩니다.

자주 묻는 질문 · 팁

오늘 사설이 안 보여요.
수집은 하루 3회(아침·오후·밤) 자동 진행됩니다. 아직 안 올라왔다면 잠시 후 다시 보거나, 화면 안내의 최근 수집일 링크로 이동하세요.
비교 분석 내용이 너무 짧아요.
상세 화면의 재생성 버튼을 누르면 최신 사설까지 반영해 다시 분석합니다(기존 내용 덮어쓰기).
사설이 엉뚱한 주제로 묶였어요.
오늘의 사설에서 해당 행에 마우스를 올려 주제 변경 → 올바른 주제로 이동하거나 새 주제를 입력하세요. 보정한 내용은 보존됩니다.
해외 사설 원문을 보고 싶어요.
사설을 열고 원문 탭으로 전환하면 일본어/영어 원문을, 매체 사이트에서 보기로 출처 페이지를 볼 수 있습니다.
로그인 계정은 개인 계정인가요?
논설실 공용 계정 1개를 함께 사용합니다. 브라우저를 닫으면 자동 로그아웃됩니다.
비교 보고서를 회의 자료로 쓰려면?
상세 화면에서 복사(마크다운) 또는 인쇄(PDF)를 사용하세요.
